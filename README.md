# Trainer-bot

**Trainer-bot** — внутренний Telegram-бот-тренажёр для обучения и практики сотрудников чата.

Бот имитирует диалог с реальным пользователем и последовательно задаёт вопросы из подготовленных наборов (кейсов).  
Сотрудник отвечает в свободной форме, как в реальном чате поддержки. По итогам прохождения теста формируется отчёт для проверки.

---

## Назначение

В отделе регулярно появляются новые сотрудники, которым требуется практика общения с пользователями и закрепление знаний по сервисам:

- Электронный дом  
- mos.ru  
- Наш город  
- другие электронные услуги

Ранее тренировки проводились вручную — опытные сотрудники задавали вопросы в тестовых чатах и проверяли ответы.  
**Trainer-bot** автоматизирует этот процесс и снижает нагрузку на команду.

---

## Как работает бот

1. Сотрудник запускает бота в Telegram
2. Выбирает направление теста (набор вопросов)
3. Бот по очереди задаёт вопросы, имитируя сообщения обычного пользователя
4. Сотрудник отвечает текстом (можно несколькими сообщениями)
5. По завершении теста бот формирует отчёт:
   - вопрос  
   - ответ сотрудника  
6. Отчёт отправляется в виде файла и может быть передан наставнику или руководителю

---

## Ключевые особенности

- Вопросы хранятся во внешних CSV-файлах
- Синхронизация вопросов с базой данных без потери старых результатов
- Для каждого ответа сохраняется **снимок текста вопроса** на момент прохождения теста
- Поддержка случайной выборки вопросов (например, «20 из 200»)
- Один вопрос может содержать несколько сообщений-ответов
- Бот не проверяет правильность ответа — предназначен для тренировки и оценки навыков

---

## Архитектура

- **Язык:** Swift  
- **Backend:** Vapor  
- **База данных:** PostgreSQL + Fluent  
- **Интерфейс:** Telegram Bot (long polling)  
- **Хранение вопросов:** CSV → синхронизация с БД  

Проект спроектирован как долгосрочный внутренний инструмент с возможностью расширения:
- добавление новых направлений
- усложнение сценариев
- развитие экзаменационных режимов
- интеграция с внутренними системами обучения

---

## Статус проекта

Проект находится в активной разработке.

На текущем этапе реализуется базовый MVP:
- прохождение теста
- сбор ответов
- формирование отчёта
